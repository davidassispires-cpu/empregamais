# Typography

Poppins is the only font family used by this website, including public pages,
vacancy cards, candidate and recruiter portals, forms, menus, and admin pages.
Use `Poppins,sans-serif` in CSS, inline styles, generated HTML/SVG, and JavaScript
style assignments. Keep font sizes and weights appropriate to the existing layout.

Use the local Poppins files in `assets/fonts/`, declared by `site-fonts.css`.
Do not add other font families, aliases, font files, external font imports, or
component-specific font overrides. Maintain this rule in all future changes.
